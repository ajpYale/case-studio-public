The problem: practice cases run out, and a third are wrong

  • MBA consulting candidates practice dozens of cases with a partner, who needs a case packet to run them.
  • Clubs share casebooks: finite, repetitive, and unlabeled for difficulty.
  • ChatGPT makes "a case" as loose prose: no exhibits, and the math is never checked.

Safety: defenses that fire

  • Prompt injection screened and fenced; agents have no tools
  • No code execution: whitelist arithmetic parser
  • Invented numbers caught by 29 code checks
  • Answer-key leaks: key never sent to the browser; code leak guard on every reply
  • Overspending: per-call, per-case and daily caps; Sol asks every run
  • Network guard: other devices see only a live case's read-only view
  • 67 automated tests (38 safety, 27 new features, 2 pages), no model calls, all passing

Impact and what I learned

  • Cost: $0.03 per case vs $2.50–$7 on paid platforms
  • Correctness: answer keys can't contradict their exhibits; casebooks: 35% flawed
  • Supply: unlimited new cases at any difficulty
  • Real use: narrated demo video; 9 problems found practicing as a candidate, all fixed

A solver agent checks the key from the candidate's side

  • Gets only what the candidate gets: prompt, clarifying answers, shared facts, exhibits. Never the key.
  • Code compares its answers with the key; a miss means a missing fact or a question that reads two ways
  • 7 Luna test cases: 1 real gap caught (a hurdle defined two ways, $1.7M vs $0.5M), fixed for ½¢
  • Costs 4–7% of a case

Live partner mode: run any case with a classmate

  • The interviewer keeps the guide; the candidate scans a QR code
  • They see only the prompt and the exhibits you release, live
  • No model calls; other devices can reach nothing else (403)

Limits and next steps

Limits

  • Luna is not reliable on Hard and Instant Offer (5 of 7 had a major issue); use Second opinion or Stronger
  • AI review samples problems; it can't prove there are none
  • Handsome Dan's voice is the browser's; insight leaks are rule-based, not code-guarded
  • Local, single-user; live mode only on the same network
  • Converted casebook cases keep the casebook's own flaws, on purpose

Next

  • Number checks during practice: Handsome Dan reacts to a wrong result without giving the answer
  • Hosted club library with sign-in; members run the club's casebook cases but can't download them
  • Terra audit of new Hard cases to measure the solver (~25¢)
  • Browser tests in CI
